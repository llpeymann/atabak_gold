* **شواهد:** `src/config/env.validation.ts`، `src/app.controller.ts`، `src/app.service.ts`، `Dockerfile`،
  `docker-compose.yml`، `src/bale/bale.service.ts`, `src/common/log-safety.ts`.
* **وضعیت:** **COMPLETE**
* **تأیید مستقل این ممیزی:**
  * بالا آمدن با محیط ناقص → خروج با پیام روشن: `EnvironmentValidationError: Missing required environment variable: PRICE_API_URL` (اجرا شد).
  * مقدار نامعتبر → `Invalid PRICE_API_URL: "not-a-url" is not a valid absolute URL` (اجرا شد).
  * `npm ci --dry-run` → سازگاری lockfile ✅ · `npm audit --omit=dev` → **۰ آسیب‌پذیری**.
  * Dockerfile: `node:22-bookworm-slim` (سازگار با `engines.node >= 20` و NestJS 11)، اجرای غیرروت (`USER node`)،
    `HEALTHCHECK`، `VOLUME /app/data`، `.dockerignore` شامل `.env`.
* **کمبودها:** ساخت واقعی ایمیج Docker در این محیط **NOT RUN** است (Docker نصب نیست) — نه شکست، بلکه اجرانشده.
